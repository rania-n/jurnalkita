# Screenshot Referensi Figma

Taruh screenshot tiap frame Figma di folder ini supaya tampilan kode bisa
disamakan dengan desain. Format bebas (`.png` / `.jpg`), tapi ikuti penamaan
di bawah biar mudah dicari.

## Cara ambil screenshot di Figma

- Pilih frame → klik kanan → **Copy/Paste as → Copy as PNG**, lalu paste/simpan ke sini.
- Atau pilih frame → panel kanan **Export** → `2x` PNG → Export.
